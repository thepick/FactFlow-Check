FactFlow Check 3.0 preview

An independent snapshot of multiplication accuracy and fluent recall. Named fact groups are assessed independently; the question allowance covers every selected group.

Standard questions allow ten seconds. Correct submitted responses under four seconds count as fluent. Extended, untimed, and teacher-recorded checks assess accuracy only.

The preview saves locally and never sends results to Google Sheets. Download or copy each result. The existing classroom version remains available.
